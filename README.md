# RC Beam Analyzer

단근 직사각형보, 복근 직사각형보, T형보의 공칭휨강도와 설계휨강도를 계산하는 데스크톱 애플리케이션입니다.

Tkinter GUI에 Matplotlib 단면도와 철근비–휨강도 그래프를 결합했으며, 같은 계산 결과를 터미널에서도 정렬된 리포트로 확인할 수 있습니다.

## 주요 기능

- `SinglyReinforcedBeam`, `DoublyReinforcedBeam`, `TBeam` 독립 해석 클래스
- 세 클래스가 공유하는 축력 평형 함수와 `scipy.optimize.root_scalar(method="bisect")` 해석
- 복근보 압축철근의 항복·비항복 상태 자동 판정
- T형보 중립축의 플랜지·복부 위치 자동 판정
- 순인장변형률에 따른 압축지배·변화구간·인장지배 판정 및 `φ` 계산
- `dt`가 직접 주어지지 않으면 최외단 인장철근 깊이를 `h-60 mm`로 계산
- T형 총단면의 도심, 단면2차모멘트 `Ig`, 균열모멘트 `Mcr` 별도 계산
- 최소·최대철근 한계 위반 시 명세에 따라 `Mn = φMn = 0` 처리
- 인장철근비 `As/(bd) = 0~3%`에 대한 공칭·설계휨강도 그래프
- 교재 예제 4-2, 4-3, 4-5 입력 프리셋
- 압축철근이 없는 T형보와 4-D25가 있는 추가 T형보 프리셋·입력 필드
- GUI 없이 실행 가능한 예제 리포트 및 그래프 저장 모드

## 계산 기준

| 항목 | 적용값 |
|---|---:|
| 콘크리트 | 일반 콘크리트 (`λ = 1.0`) |
| 적용 범위 | `0 < fck ≤ 40 MPa` |
| 콘크리트 극한압축변형률 | `εcu = 0.0033` |
| 등가응력블록 계수 | `β1 = 0.8` |
| 철근 탄성계수 | `Es = 200,000 MPa` |
| 휨 강도감소계수 | 순인장변형률에 따라 `0.65 ≤ φ ≤ 0.85` |
| 최외단 인장철근 깊이 | 미입력 시 `dt = h-60 mm` |

이 프로그램은 수업 과제 및 학습용입니다. 실제 구조물의 설계·안전성 검토에는 사용할 수 없습니다.

## Root Finding과 기존 계산 규칙

`εt`를 미지수로 `c=εcu·dt/(εcu+εt)`, `a=β1c`를 계산하고, `Cc+Cs'-T=0`을 이분법으로 풉니다. 근 탐색은 중간 반올림 없이 수행하며, 그 뒤 기존 반올림 규칙으로 강도를 계산합니다. 리포트의 축력 잔차는 반올림 전 평형해에서 구한 값입니다.

| 구분 | 유지하거나 수정한 규칙 |
|---|---|
| 강도감소계수 구간 판정 | `εt`를 미리 반올림하지 않고 한계변형률과 비교하도록 수정 |
| 변화구간 `φ` | 기존대로 선형보간 후 소수 셋째 자리로 반올림하여 강도 계산에 사용 |
| 복근보 비항복 계산 | 기존대로 `c` 소수 첫째 자리, 압축철근 변형률 소수 다섯째 자리 반올림 |
| T형보 변형률 계산 | 기존대로 `a`를 mm 단위 정수로 반올림한 뒤 `c`와 `εt` 계산 |
| 곡선·빨간 점 좌표 | 기존대로 `use_textbook_rounding=False` 정밀 계산값 사용 |
| 빨간 점 라벨 | 기존대로 기본 해석의 설계강도를 소수 첫째 자리까지 표시 |
| 출력·플롯 서식 | 기존 리포트 자릿수, 색상, 축, 철근비 범위, 경계 표시 유지 |

기본 해석의 설계휨강도는 예제 4-2 **454.722**, 예제 4-3 **483.116**, 예제 4-5 **570.317 kN·m**입니다. 예제 4-2의 `φ=0.844`는 원본의 `φ` 반올림을 유지한 결과입니다. 그래프용 정밀 해석에서는 약 `454.980 kN·m`를 사용하며, 기존처럼 점 좌표와 라벨의 계산 정밀도를 구분합니다.

추가 T형보는 `fck=27 MPa`, `fy=400 MPa`, `bf=800 mm`, `bw=400 mm`, `hf=150 mm`, `d=515 mm`, `dt=540 mm`, 인장철근 8-D25를 사용합니다. 전체 높이 `h=600 mm`는 가정이며, 최소철근 검토에 적용합니다. 기존 T형보는 `as_compression=0`이 기본값이므로 기존 입력 인터페이스를 유지합니다.

## 실행 환경

- Python 3.10 이상
- Windows 10/11 권장
- Tkinter: Python 표준 라이브러리이므로 `requirements.txt`에 포함되지 않음
- 외부 패키지: Matplotlib, SciPy

## 설치 및 GUI 실행

명령 프롬프트에서 프로젝트 폴더로 이동한 뒤, SciPy와 Matplotlib이 설치된 전역 Python으로 실행합니다. 패키지는 사용자가 직접 설치하며 프로그램은 자동 설치하지 않습니다.

```cmd
python -m pip install -r requirements.txt
python main.py
```

Python 공식 Windows 설치판에는 일반적으로 Tkinter가 포함됩니다. 최소 설치판에서 GUI 모듈 오류가 발생한다면 Python 설치 관리자의 `tcl/tk and IDLE` 구성요소를 추가합니다.

## 복근 T형보 GUI

`보 형식 → 복근 T형보`를 선택하면 압축철근 4-D25 예제를 불러와 해석한다. 상단 예제 목록에서도 `복근 T형보 (압축철근 4-D25, h=600 mm 가정)`을 선택할 수 있다. 압축철근량 `As'`와 깊이 `d'`는 별도 입력창으로 표시한다.

프로젝트 폴더의 명령 프롬프트에서 해당 GUI를 바로 열려면 다음을 실행한다. 이미 실행 중인 이전 창은 닫고 다시 실행한다.

```cmd
python main.py --doubly-t
```

## 터미널 리포트

GUI를 열지 않고 세 교재 예제를 일괄 계산합니다.

```cmd
python main.py --examples
```

계산 결과와 그래프 PNG를 함께 생성하려면 다음과 같이 실행합니다.

```cmd
python main.py --examples --save-plots outputs
```

추가 T형보 2건까지 총 5건을 실행하거나 플롯을 저장하려면 다음을 사용합니다. 기존 `--examples`는 세 예제만 실행하는 동작을 유지합니다.

```cmd
python main.py --all-examples
python main.py --all-examples --save-plots outputs
```
